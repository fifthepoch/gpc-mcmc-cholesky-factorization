# Results Report Workspace

Use this folder to collect final results for Exp0-Exp4.

## Quick Start
1. Fill `data/experiment_results_master.csv` (one row per condition).
2. Store run-level entries in `data/experiment_results_runs_master.csv` if needed.
3. Place plots in `figures/` and summary tables in `tables/`.
4. Keep experiment-specific notes in `exp0/` ... `exp4/` and `notes/`.
